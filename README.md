# Princeton Economics PhD Conference

Open `index.html` in a browser to preview the site. All conference text is in that file. Comments mark where to add the dates, call for papers, program, keynote, and organizers. Edit `styles.css` for colors, typography, and layout.

## GitHub Pages

The `website/` folder is the root of the conference website repository. In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/ (root)**, then save. Subsequent pushes to `main` update the site. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Banner

The banner in `campus-illustration.jpg` is an AI-generated illustration inspired by Princeton’s collegiate Gothic architecture. To change the banner, replace this file or update the image path and dimensions in `index.html`.
