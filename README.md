# Princeton Economics PhD Conference

Open `index.html` in a browser to preview the site. All conference text is in that file. Comments mark where to add the dates, call for papers, program, keynote, and organizers. Edit `styles.css` for colors, typography, and layout.

## GitHub Pages

Use the contents of this `website/` folder as the root of the conference website repository. Include `.nojekyll` and the photo. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the branch containing the files and **/ (root)**, then save. Subsequent pushes to that branch update the site. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
